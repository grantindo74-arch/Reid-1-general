# Reid's Build Lab

Projects and learning material Reid and his dad build together.

## What's here

- `course/index.html`: the Build Lab course site. It has a course home page and chapters with lessons and hands-on missions.
  - Chapter 01: How Cell Networks Work (lesson, 4-page infographic in `course/images/`, 5 Android phone missions)
  - Chapter 02: How the Internet Works (6-page guide, images in `course/images/`)
  - Chapter 03: Networks & the IT World (4-part study guide, images in `course/images/`)

## Viewing the course

Open `course/index.html` in a web browser. Mission answers and checkmarks are saved in that browser only.
